# MINDSCOPE

日本語の認知チャレンジ。全30問・5領域各6問。通常版60問・高難易度版40問の別々の問題プールから、選んだモードの30問を重複なしで抽出し、各領域内の順序と選択肢もランダム化。WAIS-5の領域構成を参考にした独自コンテンツであり、正式なWAIS、IQ測定、診断ではありません。標準化・年齢補正・母集団比較はありません。

## 起動

`dist/index.html`をブラウザで開くか、`dist`を任意の静的ホスティングで配信します。ビルドやインストールは不要です。Vercelは`vercel.json`の設定で`dist`を配信します。

## 内容

- 言語理解・視覚推理・流動性推理・ワーキングメモリー・処理速度を各6問
- 記憶課題は1回限りの逐次表示。表示中に他タブへ移動すると中断
- 処理速度は通常版各25秒、高難易度版各20秒。経過時間は実時刻で判定し、バックグラウンドでも期限は進行
- 回答確定後の戻る操作なし。時間切れ・スキップ・中断は正答に含めない
- 領域別正答数、全問解説、難易度を含む最大20回の端末内履歴、JSONエクスポート
- 登録は任意。ニックネーム付きのスコア一覧をSupabaseで共有。個別の回答は送信しない

## 検証

`node tests/qa.cjs`

問題抽出・選択肢シャッフルと採点整合性、旧20問履歴の互換性、問題データ、回転・反転、記号の個数、記憶課題の正答、全問採点、タイムアウト、タブ移動中断、保存失敗を検証します。アプリの進行検証にはDOMスタブを使用します。高難易度版は500セッションを生成し、複合変換・記憶・速度課題の正答、モード別の完走・採点・履歴・絞り込みを検証します。

参考：Pearson公式 WAIS-5概要 https://www.pearsonassessments.com/content/dam/school/global/clinical/us/assets/wais-5/wais-5-overview-brochure.pdf

デザインにはCSS・SVGを使用。オンライン時のみGoogle Fontsを読み込み、接続できない場合は端末のフォントで表示します。

記憶問題の数字・位置、処理速度の記号や対応表は開始ごとに生成します。出題した問題と選択肢を結果と一緒に保存するため、履歴の解説は後の出題から影響を受けません。ランダム出題ごとの難易度は統計的には等化していません。

## Supabaseの共有記録

接続先の選択後、`database/schema.sql`をそのSupabaseプロジェクトに適用します。Vercelの環境変数`SUPABASE_URL`と`SUPABASE_PUBLISHABLE_KEY`を設定して再デプロイしてください。ビルド時に`dist/supabase-config.js`へ公開用設定だけが書き込まれます。service_role/secret keyは使用しません。

- 参加者が結果画面でニックネームと表示同意を入力して登録
- 最新順に25件ずつ一覧。通常版・高難易度版の絞り込みに対応。20問版・30問版の過去の端末内結果も本人操作で登録可能
- 同じ結果はUUIDで重複登録を防止。通信失敗時に同じIDで再試行
- RLSと列単位権限を使用。参加者にはSELECTと必要列のINSERTだけを許可
- 得点は領域別正答数の和からDBが生成。日時の登録時刻はサーバー側で生成
- UPDATE/DELETE権限なし。削除対応は管理者がSupabaseで実施
- ニックネームは本人確認なし。得点はブラウザからの申告値で、改ざん防止済みの競技ランキングではない
- 記録の読み取りはpublishable keyで許可されるため、登録時には他者にも表示される旨を案内

DB接続・実テーブルへの読書き・アドバイザーの検証は、接続先の決定後に行います。接続設定が空の場合、テストと端末内履歴は利用でき、共有スコア登録は設定待ちとして無効になります。

## 高難易度版（追加）

ホームで「通常版」または「高難易度版」を選択して開始します。高難易度版は専用40問から5領域各6問を出題。複数条件・量化の推論、5×5図形の複合変換、条件付き確率や組合せ、8〜11桁の保持・並べ替え、記憶の更新、情報量の多い処理速度課題を含みます。記憶表示は0.75秒、速度課題は20秒。得点は未標準化の正答数で、通常版と数値を直接比較しません。

既存のSupabaseには `database/upgrade-modes.sql` を一度だけ適用します。既存の共有記録は通常版として扱い、新しい結果には `mode` を保存します。新規構築の場合は更新後の `database/schema.sql` のみを使用します。

GitHubのブラウザアップロードでフォルダが省略された構成も、VercelのInstall Commandで公開前に再配置できます。このリリースの更新用ファイルは、フォルダなしでもアップロードできる形でも用意しています。
